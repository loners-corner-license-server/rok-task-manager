# ROK Task Manager Website

A free static website for ROK Task Manager by Loner's Corner.

## 1) Add your real links
Open `script.js` and replace:

- `https://whop.com/REPLACE-WITH-YOUR-STORE`
- `https://discord.gg/REPLACE-WITH-YOUR-INVITE`

## 2) Test locally
Double-click `index.html` or open it in any browser.

## 3) Publish free with GitHub Pages
1. Create a free GitHub account if you do not already have one.
2. Create a new PUBLIC repository, for example `rok-task-manager`.
3. Upload every file and the `assets` folder from this website folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. GitHub will display your free website URL after deployment.

## Optional custom domain
You can later buy a domain and connect it to GitHub Pages without changing this site.

## Important before launch
- Replace the Whop URL.
- Replace the Discord invite.
- Review `legal.html` and add your real refund/license/support terms.
- Verify every feature statement matches the current software build.
